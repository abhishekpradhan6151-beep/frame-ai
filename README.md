FRAME

An AI-powered short-form video content creation platform.

FRAME helps content creators turn an idea into ready-to-edit short-form video content.

Product vision

Build a clean, fast, responsive web application with a premium, minimalist interface inspired by Apple’s design language.

Core features

1. Home — Enter a content idea and configure platform, language, tone, and duration.
2. Content Studio — Generate and edit hooks, scripts, captions, and calls to action.
3. Quick Edits — Make focused changes to individual sections without regenerating everything.
4. My Creations — Save, reopen, rename, and delete previous creations.
5. Settings — Configure default preferences and manage locally saved data.

Design principles

* Minimalist black, white, and subtle grey palette.
* Responsive layouts for phones, tablets, and desktops.
* Clear typography, generous spacing, and simple navigation.
* Accessible controls, useful empty states, and understandable error messages.

Technical principles

* Use a maintainable, modern web stack.
* Keep API keys and secrets out of client-side code and Git.
* Validate inputs and handle failures gracefully.
* Add automated tests and a GitHub Actions workflow.
* Prefer free or low-cost services.
* Keep existing work safe through small, reversible changes.

Development roadmap

1. Establish the project structure and working development environment.
2. Build the responsive user interface.
3. Implement the content editor and local persistence.
4. Add automated tests and continuous integration.
5. Integrate a real AI provider through a secure server-side endpoint.
6. Test the production build and deploy.

Important

Generated sample content must never be presented as real AI output. Clearly distinguish demo functionality from live AI features.
